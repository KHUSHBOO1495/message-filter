Stack
Backend - Node.js + Express.js
Database: MongoDB Atlas + Mongoose
AI: Groq API
Frontend (Demo): React

I used express because it is lightweight for building APIs
MongoDB provides document based schema

The AI is used for understanding users message and decide the meaning of that message. It calculates priority and save the tickets.

For a time I have skipped the user authentication and authorization

Before taking it to the production I would like to add a feature where AI will understand the natural and grammatically incorrect messages from user.
